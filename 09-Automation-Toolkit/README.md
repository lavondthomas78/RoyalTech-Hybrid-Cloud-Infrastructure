\# Royal Technology Solutions Automation Toolkit



\## Purpose



This toolkit contains administrative, validation, backup, and operational scripts used to maintain the Royal Technology Solutions hybrid infrastructure environment.



\## Categories



\### PowerShell



Windows infrastructure automation:



\- Server health checks

\- Virtual machine inventory

\- Active Directory validation

\- Service monitoring

\- Backup validation



\### PostgreSQL



Database administration:



\- RoyalDB backup

\- Database validation

\- User auditing

\- Health checks



\### AWS



Cloud operations:



\- EC2 inventory

\- RDS validation

\- S3 backup verification

\- Cloud resource reporting



\## Environment



Primary platforms:



\- Windows Server 2025

\- PostgreSQL 18

\- AWS

\- Veeam Backup

\- VirtualBox

\- pfSense



\## Supported Systems



This toolkit is designed to support the Royal Technology Solutions hybrid infrastructure environment, including:



\### On-Premises Infrastructure



\- Domain Controllers (DC02 / BDC02)

\- DNS Services

\- DHCP Services

\- IIS Web Servers

\- PostgreSQL Database Servers

\- File Services

\- Veeam Backup Infrastructure



\### Cloud Infrastructure



\- Amazon EC2

\- Amazon RDS PostgreSQL

\- Amazon S3 Storage

\- AWS IAM Resources



\### Security Infrastructure



\- pfSense Firewall

\- IDS/IPS Monitoring

\- Network Validation Tools
